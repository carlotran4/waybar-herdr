# Changelog

All notable changes to this project will be documented here.

## [Unreleased]

## [0.1.1] - 2026-07-26

### Added

- Animated, synthetic-agent demonstration for the README.

### Fixed

- Explicit `--session` now overrides an inherited `HERDR_SOCKET_PATH`, matching CLI expectations and allowing named sessions from inside Herdr panes.

## [0.1.0] - 2026-07-25

### Added

- Event-driven Herdr status updates over the local socket API.
- Compact status counters and detailed agent tooltips.
- Highest-priority agent focusing with optional Hyprland window focusing.
- Default and named-session Waybar examples.
